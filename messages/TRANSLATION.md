# For translators — English → Amharic

**Only file they need:** [`english-to-amharic.json`](english-to-amharic.json)

## Format

```json
{
  "Home": "መነሻ",
  "Visit Us": "",
  "About Our Church": "ስለ ቤተ ክርስቲያናችን"
}
```

- **Key** = English text (do not change)
- **Value** = Amharic translation only
- Empty `""` = not translated yet — please fill in Amharic

## Rules

1. Do **not** change the English keys.
2. Values must be **Amharic only** — never leave English as the value.
3. Keep placeholders exactly as written, for example `{count}`, `{index}`, `{current}`, `{total}`.
4. When finished, every value should be Amharic (no empty strings).

## Developers

After translation is complete, paste Amharic values back into `am.json` (or ask a developer to merge this file into the app).
